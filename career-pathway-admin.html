자동 번역 안내

프로그램 추가·수정 시 한국어를 입력한 뒤 "🌐 한국어 → 5개 언어 자동 번역" 버튼을 누르면, 무료 번역 서비스(MyMemory)를 통해 영어·베트남어·우즈베크어·미얀마어·몽골어로 자동 번역됩니다.
· 별도의 API 키나 결제 등록이 필요 없습니다.
· 무료 서비스 특성상 하루 사용량 제한(익명 약 5,000단어/일)이 있으며, 기계 번역이므로 공식 게시 전 원어민 검수를 권장합니다.
· 번역 후 각 언어 탭에서 직접 수정할 수 있습니다.

통계 지표

공개 페이지 하단 통계 카드에 표시되는 값입니다. 자동 연동 KPI가 확정되기 전까지는 수기로 입력합니다.

연동 안내

· 프로그램 목록과 통계는 sss-works Firebase 프로젝트의 careerPathway/ 경로에 저장되며, 기존 관리 시스템(index.html)과 같은 DB를 공유합니다.
· 공개 페이지(career-pathway.html)는 이 경로를 실시간 구독하므로, 저장 즉시 별도 배포 없이 반영됩니다.
· 대상군(학령기/성인학습자/국제학생) 분류는 현재 국제학생 프로그램만 채워져 있으며, 나머지 프로그램은 추가되는 대로 이 화면에서 등록하면 됩니다.
